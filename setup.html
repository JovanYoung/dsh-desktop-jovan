第一步：安装 dsh 运行环境

  1. 安装 Node.js（dsh 的运行环境）： https://nodejs.org （下载 LTS 版，一路下一步）
  2. 打开 PowerShell，粘贴以下命令（会自动创建 D:\dsh-app 并安装 dsh）：
    cd D:\ mkdir dsh-app cd dsh-app npm init -y npm install @deepseek-ai/dsh --registry=https://registry.npmmirror.com
  3. 安装完成后点击下方「重新检测」，或重启本应用。

第二步：填写 DeepSeek API Key

还没有 Key？打开 platform.deepseek.com →「API Keys」→「创建新密钥」→ 复制。

关于你的 API Key 安全

🔒 你的 Key 只保存在本机，绝不上传任何服务器

Key 使用 Windows 系统级加密（DPAPI）存到你的用户目录，只通过环境变量注入本地 dsh 进程。没有网络调用、没有云同步、不会出现在任何日志里。下面是处理 Key 的后端代码，完全开源，可自行核对：

// main.js —— API Key 加密存储（Windows DPAPI / safeStorage）
function settingsFile() {
  return path.join(app.getPath('userData'), 'settings.json');
}
// 保存：本机加密后落盘
if (safeStorage.isEncryptionAvailable()) {
  data.apiKeyEnc = safeStorage.encryptString(key).toString('base64');
}
// 读取：仅本机解密
data.apiKey = safeStorage.decryptString(Buffer.from(data.apiKeyEnc, 'base64'));
// 注入本地 dsh 进程（仅本机环回）
env.DEEPSEEK_API_KEY = key;
